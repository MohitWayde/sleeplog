1111# Sleep Calendar (SleepLog)

A minimalist, responsive sleep tracker web app hosted with GitHub Pages.

## Features
- 🌙 **Sleep & Wake Tracking**: Log bedtime and wake-up time for each day.
- 📊 **Monthly Statistics**: View average sleep duration, complete logs, and longest sleep.
- 💾 **Data Backup**: Export and import your sleep data anytime in JSON format.
- 🌗 **Light / Dark Mode**: Toggle between light and dark themes.
- 📱 **Mobile-Friendly**: Clean, responsive layout built with Tailwind CSS.
